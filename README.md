**Analysis of Stock prices using Python and Power Bi**

**Key analysis performed**
Data cleaning and preprocessing
Exploratory data analysis (EDA)
Data visualization using python 
And interactive dashboard creation using Power Bi

This dashboard provides a comprehensive analysis of stock market performance by tracking price movements, trading volume, and key trends over time. It highlights high-performing stocks and the relationship between price and trading activity to support data-driven investment decisions.
